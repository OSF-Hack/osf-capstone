- **18 September:** Implement action card, discrepancy report and escalation path.
- **19 September:** Add reviewed translation, offline behaviour, accessibility and failure states.

## Definition of done

- A new user understands the problem within 30 seconds.
- The complete golden journey works on a mobile viewport.
- Every material civic claim shows its source and review date.
- Missing or conflicting evidence is visible.
- No sensitive personal data is required for the primary journey.
- Lint, typecheck, tests and production build pass.
- The repository, video, deck and written summary tell the same story.
