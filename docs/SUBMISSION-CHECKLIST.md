# Submission checklist

## Repository

- [ ] Public repository and stable deployment
- [ ] Problem, user, track and value proposition
- [ ] Local setup and test instructions
- [ ] Architecture and trust model
- [ ] Source register and freshness policy
- [ ] Privacy, accessibility and low-bandwidth decisions
- [ ] AI-development disclosure
- [ ] Known limitations

## Demo

- [ ] Human problem in the opening 20 seconds
- [ ] One uninterrupted golden journey
- [ ] Visible sources and verification status
- [ ] Clear next action and escalation route
- [ ] Offline/low-bandwidth behaviour
- [ ] Scaling through service packs

## Final quality gate

- [ ] No invented civic information
- [ ] No exposed secret or personal data
- [ ] No broken link or private asset
- [ ] Fresh-browser and mobile test completed
- [ ] Submission completed before 21 September 2026 at 18:00 UTC
